## Best Module: GeneralLedgerView (Sổ cái)

### Why
- Uses shared design system (AccountingPanelCard, AccountingKpiCard, AccountingFilterCard)
- 5-level typographic hierarchy (23/16/13.5/12/11)
- Consistent CornerRadius=14, Shadow BlurRadius=14 Opacity=0.06
- Page background #F5F8FC creates professional canvas
- DataGrid with styled headers, alternating rows, hover/select states
- Animated slide-in panels
- Color-coded action buttons (orange/blue/red/green)
